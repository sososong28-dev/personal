# 学员作业模板包

## 使用说明

这个模板包用于配合《从个人经历到商业名片》课程。

填写原则：

- 能证明的写，不能证明的先空着。
- 先整理结构，再追求文案。
- 公开页写少一点，私密页写深一点。
- 每个项目都要从“做了什么”改成“解决了什么问题”。

## 模板 8：AI/Codex 改版提示词

### 公开页改版提示词

```text
基于当前个人网站，不要改变原有首页的核心设计元素。

目标：优化公开页，让它更适合面向企业高管、投资者和合作方展示。

要求：
1. 首页保持高效和设计感，不堆详细内容。
2. 项目只做入口或点击切换，不直接暴露私密详情。
3. 保留公开页和私密页的内容边界。
4. 移动端必须适配，不能出现重叠、裁切、无法滚动。
5. 联系方式放在明显位置。
6. 输出本地检查地址和截图。
```

### 项目案例拆解提示词

```text
请把这个项目拆成一个适合放入个人网站私密案例库的结构。

不要只总结成果，要重点讲：
1. 项目背景；
2. 用户或业务问题；
3. 我的关键判断；
4. 如何拆解；
5. 关键动作；
6. 结果和证据；
7. 可复制能力；
8. 哪些内容适合公开，哪些内容需要脱敏或放在私密页。
```

### 移动端 UI 检查提示词

```text
请检查公开页和私密页的移动端 UI。

重点检查：
1. 首屏是否重叠；
2. 图片是否裁切过度；
3. 按钮文字是否溢出；
4. 页面是否能上下滚动；
5. 是否有横向滚动；
6. 项目卡片是否能点击切换；
7. 联系方式是否清晰可见。

完成后输出截图路径和问题清单。
```

## 模板 10：对外转发话术

### 面向高管

我整理了一个个人公开页，主要沉淀我在产品企划、GTM、商品经营和 AI 消费者产品方向的项目经验。公开页只放了脱敏信息，完整案例可以登录后查看。

### 面向投资者

我把过往项目经历整理成了一个公开页 + 私密案例库，重点呈现消费者产品、AI 应用、商品经营和 GTM 的判断与落地过程。如果你方便，可以先看公开页，我再按需开放具体案例。

### 面向合作方

这是我的个人项目档案页，里面有公开能力介绍和部分项目入口。完整项目材料做了权限控制，适合后续深入沟通时查看。
