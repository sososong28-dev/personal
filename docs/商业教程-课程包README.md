## 第一版 MVP 售卖建议

建议先做小规模验证，不要一开始录完整大课。

第一版只交付：

1. 3 节录播课：
   - 为什么个人网站不是作品集；
   - 如何拆解个人定位和项目案例；
   - 如何用 AI/Codex 迭代并上线。
2. 4 个核心模板：
   - 个人网站商业定位表；
   - 项目案例拆解表；
   - 公开页文案模板；
   - 上线检查清单。
3. 1 个贯穿案例：
   - 何坚松个人网站公开页 + 私密案例库。

## 推荐销售路径

### 第一步：低价验证

产品形式：

- 录播 + 模板包。

价格：

- 199-399 元。

验证目标：

- 是否有人愿意为“个人网站产品化方法”付费；
- 哪类人最感兴趣；
- 他们卡在定位、案例、设计、部署中的哪一步。

### 第二步：标准版升级

产品形式：

- 录播 + 模板包 + 作业点评。

价格：

- 699-1299 元。

验证目标：

- 学员是否愿意为项目案例反馈付费；
- 哪些案例最需要人工打磨；
- 是否可以批量化点评。

### 第三步：高阶陪跑

产品形式：

- 1 对 1 定位梳理 + 案例打磨 + 网站部署陪跑。

价格：

- 2999-9999 元。

验证目标：

- 是否能形成高客单服务；
- 是否可以沉淀更多案例；
- 是否可以反向优化录播课内容。

## 内容发布节奏

### 预热内容

1. 为什么你的简历不能替你成交？
2. 个人网站不是作品集，而是信任入口。
3. 项目案例不要写“做了什么”，要写“解决了什么问题”。
4. 公开页和私密页为什么要分开？
5. 用 AI 做个人网站，最容易翻车的 5 个点。

### 转化内容

1. 展示公开页前后对比。
2. 展示项目案例从散乱材料到结构化案例的过程。
3. 展示移动端 UI 修复过程。
4. 展示 Codex 如何根据截图和文件改版。
5. 展示上线后公开页、私密页和项目入口。

### 成交内容

1. 发布课程销售页。
2. 发布第一节课免费试听。
3. 发布模板包部分截图。
4. 开放 10 个标准版名额。
5. 开放 3 个高阶陪跑名额。
